# Datasets
`demo_aerial.mp4` is generated by `python scripts/make_demo_video.py` (synthetic, deterministic).
For real footage use public UAV datasets (e.g. VisDrone, UAVDT, Stanford Drone) or any recorded MP4/MOV/AVI,
set `DETECTOR=yolo`, and attach simulated GPS via the mission's start lat/lon/altitude/heading.
