# Fire and Smoke Response

## Detection handling
A FIRE_SMOKE event is created when the detector reports fire or smoke for consecutive frames. Operators must verify the evidence frame before escalating.

## Response procedure
1. Verify the evidence frame visually.
2. Escalate immediately to the emergency coordinator.
3. Keep the drone feed on the affected area and keep tracking nearby vehicles and persons.
4. Generate an incident report after the event is closed.
